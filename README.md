## Description
This is a simple Java program that calculates an employee's total salary based on their basic salary, House Rent Allowance (HRA), and bonus percentage entered by the user.

## Features
- Accepts employee name and basic salary.
- Takes HRA and bonus percentages as input.
- Calculates total salary.
- Uses constructors and methods.
- Validates negative input values.

## Formula
- **HRA** = Basic Salary × HRA Percentage / 100
- **Bonus** = Basic Salary × Bonus Percentage / 100
- **Total Salary** = Basic Salary + HRA + Bonus

## Concepts Used
- Java classes and objects
- Constructors
- Methods
- User input using Scanner
- Conditional statements

## How to Run
1. Save the file as Employee.java.
2. Compile using javac Employee.java.
3. Run using java Employee.
